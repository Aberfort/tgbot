# Telegram Channel Monitor & LLM Rewriter Bot

Готовий до продакшену асинхронний Telegram-бот, який моніторить публічний канал-джерело через **Telethon (MTProto userbot)**, фільтрує та дедуплікує контент, переписує текст за допомогою **Google Gemini API (`google-genai`)** і публікує пости у ваш цільовий канал через окремого бота (з підтримкою премодерації або повної автоматизації).

## Основні можливості
- **Читання джерела через MTProto**: підписка на `events.NewMessage` та `events.Album` (альбоми з кількома фото/відео обробляються як єдиний пост).
- **Повне перезавантаження медіа**: фото, відео та альбоми завантажуються локально й заново публікуються у ваш канал без використання `forward` (жодних міток чужого каналу). Після публікації тимчасові файли автоматично видаляються.
- **Розумний рерайт через Gemini API**: системний промпт винесено у файл `prompts/rewrite.txt` і перечитується при кожному запиті — його можна редагувати на льоту без перезапуску контейнера.
- **Дедуплікація та фільтрація**: перевірка за `source_msg_id`, `grouped_id` та SHA-256 хешем тексту у SQLite (`aiosqlite`). Автоматичний пропуск репостів, постів без тексту, коротких повідомлень (`MIN_LENGTH`) та реклами (`STOP_WORDS`).
- **Режим модерації (`MODERATION=true/false`)**: чернетка надсилається адміністратору в приватні повідомлення з inline-кнопками `✅ Опублікувати`, `✏️ Редагувати`, `❌ Відхилити`.
- **Контроль частоти публікацій**: асинхронна черга з затримкою між постами (`PUBLISH_DELAY_SEC`), лімітом постів на годину (`MAX_POSTS_PER_HOUR`) та підтримкою «тихих годин» (`QUIET_HOURS`).

## Структура проєкту
```text
.
├── app/
│   ├── __init__.py
│   ├── config.py        # Конфігурація через pydantic-settings (.env)
│   ├── filters.py       # Фільтри репостів, довжини, стоп-слів та SHA-256 хеш
│   ├── listener.py      # Telethon userbot: підписка на джерело та конвеєр обробки
│   ├── moderation.py    # Inline-кнопки модерації та редагування чернеток
│   ├── publisher.py     # Черга публікацій, ліміти, тихі години, очищення медіа
│   ├── rewriter.py      # Клієнт Gemini API з експоненційним retry та лімітами довжини
│   └── storage.py       # Асинхронне сховище SQLite (aiosqlite)
├── prompts/
│   └── rewrite.txt      # Системний промпт для LLM
├── main.py              # Точка входу, логування з ротацією, graceful shutdown
├── requirements.txt
├── Dockerfile
├── docker-compose.yml
└── .env.example
```

## Швидкий старт

### 1. Підготовка конфігурації
```bash
cp .env.example .env
```
Заповніть `.env` своїми значеннями `API_ID`, `API_HASH`, `BOT_TOKEN`, `GEMINI_API_KEY`, `SOURCE_CHANNEL`, `TARGET_CHANNEL`, `ADMIN_USER_ID`.

### 2. Перша авторизація Userbot-сесії (одноразово)
Оскільки Telethon userbot при першому запуску запитує номер телефону та код підтвердження з Telegram/SMS, виконайте перший запуск інтерактивно:

```bash
docker compose run --rm tg-rewriter-bot python main.py
```
Введіть номер телефону та код із Telegram. Після появи повідомлення `Бот повністю готовий до роботи!` натисніть `Ctrl+C` — файл сесії збережеться у папці `./sessions/`.

### 3. Запуск у фоновому режимі
```bash
docker compose up -d --build
```
Перегляд логів:
```bash
docker compose logs -f
```
